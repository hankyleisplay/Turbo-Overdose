# Turbo-Overdose

用 [Three.js](https://threejs.org/) 製作的 3D 街頭賽車遊戲，直接在瀏覽器執行，不需要安裝。

和 5 台 AI 對手跑 3 圈，從最後一位出發，靠甩尾集氮氣、在直線上爆發超車。

## 操作

| 按鍵 | 動作 |
| --- | --- |
| W / ↑ | 油門 |
| S / ↓ | 煞車 / 倒車 |
| A D / ← → | 轉向 |
| 空白鍵 | 甩尾（甩尾時會累積氮氣） |
| Shift | 氮氣加速 |
| R | 回到賽道 |
| C | 切換視角（追車 / 車頭） |
| M | 靜音 |
| P / Esc | 暫停 |

手機與平板會自動顯示觸控按鈕。

## 功能

- 程式生成的封閉賽道：路緣石、砂石緩衝區、護欄、起終點拱門、看台觀眾、樹林與遠山
- 街機式物理：抓地力、甩尾側滑、離開路面減速、撞牆反彈
- 5 台 AI：依彎道曲率自動煞車、換線、互相閃避，三種難度
- HUD：名次、圈數、總時間 / 單圈 / 最佳單圈（存在瀏覽器）、小地圖、速度表、氮氣條
- Web Audio 合成的引擎聲、輪胎尖叫與音效

## 本機執行

ES module 需要透過 HTTP 載入，在專案資料夾執行：

```bash
python -m http.server 8765
```

然後打開 <http://localhost:8765>。

## 檔案

- `index.html` — 頁面結構與 HUD、選單
- `style.css` — 介面樣式
- `game.js` — 遊戲本體（場景、賽道、車輛、物理、AI、音效）
