# Turbo-Overdose

用 [Three.js](https://threejs.org/) 製作的 3D 街頭賽車遊戲，直接在瀏覽器執行，不需要安裝。

**立即遊玩：<https://hankyleisplay.github.io/Turbo-Overdose/>**

和 5 台 AI 對手跑 3 圈，從最後一位出發，靠甩尾集氮氣、在直線上爆發超車。贏得獎金買新車、改裝，一路拿下三個盃賽。

## 遊戲模式

- **生涯錦標賽**：新手盃（簡單）→ 職業盃（普通）→ 傳奇盃（困難），每個盃賽 3 場、依名次拿積分，拿下總冠軍才能解鎖下一個
- **快速比賽**：自選賽道與難度，名次越前、難度越高，獎金越多
- **計時賽**：獨自跑 3 圈，比自己的幽靈車還快就會存成新的幽靈車；刷新最佳單圈有獎金
- **車庫**：4 台車（Street GT / Blade R / Brute V8 / Apex Hyper），每台可改裝引擎、輪胎、氮氣各 3 級，可換顏色

## 線上功能

- **線上對戰**：建立房間會得到 4 碼代碼，朋友輸入代碼就能加入（最多 6 人）；房主選賽道後同步倒數開跑，名次與完賽時間即時同步，賽後可回房間再賽一場
- **線上排行榜**：每位玩家在每條賽道的最佳單圈，前 20 名；刷新個人最佳時自動上傳

線上功能使用 Firebase，需先依照 [FIREBASE_SETUP.md](FIREBASE_SETUP.md) 設定；網址加上 `?localnet` 可用本機雙分頁測試。

## 包裝與呈現

- **開始畫面與轉場**：載入畫面、「按任意鍵開始」，畫面切換時淡入淡出
- **比賽開場**：起跑前鏡頭從車頭繞到車尾並顯示賽道名稱（按任意鍵跳過）
- **背景音樂**：即時合成的 synthwave 配樂，選單與比賽各一種曲風；設定中可調整音樂 / 音效音量
- **重播**：比賽結束後可觀看整場重播，有轉播、追車、側拍、空拍、低角度鏡頭自動切換；空白鍵暫停、← → 倒轉 / 快轉、↑ ↓ 速度、C 換鏡頭、Tab 換車
- **拍照模式**：暫停選單進入，自由旋轉鏡頭、調整視角、五種濾鏡（原色 / 黑白 / 復古 / 電影 / 霓虹），可存成 PNG

## 賽道

| 賽道 | 特色 |
| --- | --- |
| 翠綠山谷 | 中高速彎道與長直線，松林與雪峰 |
| 赤岩峽谷 | 夕陽沙漠、平頂岩山與仙人掌，超長直線接髮夾彎 |
| 冰封雪嶺 | 雪地低抓地力，連續技術彎 |

進度（金錢、車輛、改裝、盃賽、最佳單圈、幽靈車）存在瀏覽器裡，可在「設定」清除。

## 操作

| 按鍵 | 動作 |
| --- | --- |
| W / ↑ | 油門 |
| S / ↓ | 煞車 / 倒車 |
| A D / ← → | 轉向 |
| 空白鍵 | 甩尾（甩尾時會累積氮氣） |
| Shift | 氮氣加速 |
| R | 回到賽道 |
| C | 切換視角（近追車 / 遠追車 / 車頭） |
| M | 靜音 |
| P / Esc | 暫停 |

**搖桿（Xbox / PS）**：RT 油門、LT 煞車、左搖桿轉向（類比）、A 氮氣、B / X 甩尾、Y 切換視角、Back 回到賽道、Start 暫停，撞擊與壓路緣石會震動。

手機與平板會自動顯示圖像化的觸控操作：左邊是方向盤（按住左右拖曳，類比轉向），右邊是油門與煞車踏板、手煞車拉桿，以及顯示剩餘量的氮氣瓶。

## 功能

- 程式生成的封閉賽道：路緣石、砂石緩衝區、護欄、起終點拱門、看台觀眾、樹林與遠山
- 畫面：物理天空、環境反射、透明烤漆車身、光暈（Bloom）、速度徑向模糊與暗角、胎痕、輪胎煙、砂石揚塵、撞牆火花
- 車輛物理：自行車模型 + Pacejka 輪胎曲線、前後載重轉移、六速自排、下壓力、ABS、循跡控制與車身穩定輔助
- 手感：甩尾時鏡頭會看向行進方向、隨速度變化的視角與震動、車身側傾與點頭
- 畫質設定：低 / 中 / 高（手機預設低）
- 5 台 AI：依彎道曲率自動煞車、換線、互相閃避，三種難度
- HUD：名次、圈數、總時間 / 單圈 / 最佳單圈（存在瀏覽器）、小地圖、速度表、氮氣條
- Web Audio 合成的引擎聲（多重泛音、渦輪哨音、洩壓閥、回火）、輪胎尖叫與音效

## 本機執行

ES module 需要透過 HTTP 載入，在專案資料夾執行：

```bash
python -m http.server 8765
```

然後打開 <http://localhost:8765>。

## 檔案

- `index.html` — 頁面結構與 HUD、選單
- `style.css` — 介面樣式
- `game.js` — 遊戲主程式（流程、AI、輸入、相機、音效、HUD、選單）
- `tracks.js` — 賽道定義與主題場景生成
- `data.js` — 車款、改裝、盃賽、獎金與存檔
- `physics.js` — 車輛動力學
- `car.js` — 程式生成的四種車身與幽靈車
- `fx.js` — 天空、後製特效與濾鏡、胎痕、火花、煙霧
- `music.js` — 即時合成的背景音樂
- `net.js` — 線上排行榜與多人連線（Firebase / 本機測試後端）
- `firebase-config.js` — Firebase 網頁設定
- `firestore.rules`、`database.rules.json` — Firebase 安全規則
